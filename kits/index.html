Três kits de cultivo

Cada kit traz os arquivos que cultivam um agente, já estruturados e com um exemplo fictício preenchido para você ver o tamanho certo. Regras: uma página boa vale mais que vinte; toda correção vai no arquivo, não na conversa; revisão semanal; nenhum segredo dentro dos arquivos.

💬 Kit pessoal

Para IA de chat (ChatGPT, Claude, Gemini). Sobre mim, regras, exemplos, memória, diário de falhas. Você cola nas instruções do chat.

Baixar kit-pessoal.zip ver no GitHub

🤖 Kit Jarvis

Para agente com ferramentas (Claude Code, Codex, OpenClaw). CLAUDE.md e AGENTS.md, memória, diário de falhas, segurança, dois runbooks. Vai na pasta em que o agente trabalha.

Baixar kit-jarvis.zip ver no GitHub

🏢 Kit empresa

Para um agente num processo. Ficha do agente, contexto, vinte exemplos anotados, scorecard, diário de falhas. Um processo, um agente, um indicador.

Baixar kit-empresa.zip ver no GitHub

Prefere que o agente escreva os arquivos por você? Instale as skills /cultivar e /revisao-semanal. Não sabe por onde começar? Faça o diagnóstico. Quer a ficha preenchida agora? Use o gerador. O repositório é um template do GitHub: "Use this template" cria a sua cópia com tudo.
