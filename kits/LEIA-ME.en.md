# Cultivation kits

Three folders, one per garden. Each one contains the files that cultivate an agent, already structured and with a fictional example filled in so you can see the right size. Kit files are in Portuguese; the structure and the LEIA-ME explain each file.

| Kit | For whom | Where the files go |
|---|---|---|
| `kit-pessoal/` (personal) | Anyone who uses AI in a chat (ChatGPT, Claude, Gemini) and wants it to work with them over time | In a folder of yours. You paste the contents at the start of the conversation or into the chat's custom instructions / project. |
| `kit-jarvis/` | Anyone who uses an agent with tools (Claude Code, Codex, OpenClaw, and similar) | In the folder where the agent works. `CLAUDE.md` (Claude Code) or `AGENTS.md` (Codex) is read automatically. |
| `kit-empresa/` (business) | Anyone about to put an agent into a company process | In the agent's project folder, or in the prompt system of the tool the company uses. |

Rules that apply to all three:

1. **Copy the folder, delete the fictional example, and write your own.** One good page is worth more than twenty dumped in.
2. **Every correction goes in the file, not in the conversation.** If you explained the same thing twice, a rule or an example is missing.
3. **Review every week (personal and Jarvis) or every two weeks (business).** `FALHAS.md` (the failure log) is the raw material; each line becomes a change in the context, the rules, or the examples.
4. **No secrets inside the files.** Keys, passwords, and tokens stay out; only the path or the name of where they live goes in here.

Ready-made zips: `kit-pessoal.zip`, `kit-jarvis.zip`, `kit-empresa.zip` (generated by `build.sh`).
