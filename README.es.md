# 🌱 IA Cultivada — no se programa, se cultiva

🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 Español

[![IA Cultivada](assets/banner.jpg)](https://inematds.github.io/iacultivada/es/)

Los modelos de IA se **cultivan, no se construyen**: los laboratorios crean las condiciones (arquitectura, datos, objetivo, cómputo, entrenamiento, feedback) y las capacidades emergen. Este proyecto toma esa idea y muestra **cómo aplicarla** en tres jardines: la vida personal, tu Jarvis (asistente personal agéntico) y los negocios.

## La idea en una línea

> Antes, programábamos el comportamiento. Ahora, programamos el proceso que produce el comportamiento.

Los ocho elementos del cultivo: **función, contexto, herramientas, reglas, ejemplos, memoria, evaluación, feedback**. El ciclo: **proceso → agente → ejecución → resultado → evaluación → feedback → agente mejor**.
